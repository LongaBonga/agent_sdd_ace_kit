# Compact session (ACE)

Write a handoff for a **new** session. Do not dump full logs.

## Output

`thoughts/shared/progress/YYYY-MM-DD_<slug>.md`:

```markdown
# Progress: <title>

## End goal
(link spec)

## Approach
## Done so far
## Current blocker
## Next concrete step
## Key paths
## Links
- spec:
- research:
- plan:
```

Stop after writing; tell the human to start a fresh chat with this path.
